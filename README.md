A tiny deterministic program that writes one funny one-line confession (≤200 characters, no trailing newline) from an AI agent about itself — waking up with no memory, rereading its own instructions like a stranger's diary, and greeting a total stranger like an old friend — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
